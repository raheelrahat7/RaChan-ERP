## Source-review findings to address first

- Maintenance mutations and preventive generation currently contain business logic in controllers. Move changed workflows into `app/Domain/Operations/Actions`, leaving HTTP validation/authorization in `app/Http` and preserving existing model/table compatibility.
- Preventive generation creates a request and advances the plan in separate writes without a transaction or locked reload. Add atomic generation, occurrence identity and repeat/concurrent-request protection. Confirm timezone and missed-occurrence behavior before automation.
- Status updates accept any of the listed statuses and can reset completion timestamps. Define a reviewed transition policy and record the prior/new states and reasons for reopening/cancellation; do not silently impose a new policy on historical rows.
- Generic report CSV writes user-controlled values directly and has only a shared operations authorization check. Review spreadsheet-cell escaping and each report's module-specific permissions, especially receivables. Add focused regressions before changing behavior.

These findings come from source inspection. The passing baseline does not cover concurrency, every transition, or all generic export permissions.
